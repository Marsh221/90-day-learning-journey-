# 90-Day Coding Roadmap

A flexible plan that prioritizes foundations before moving into more advanced tools. Each phase lasts approximately 30 days; repeat or extend topics when needed.

## Phase 1 — Days 1–30: Python foundations

### Topics
- Set up and run Python files in VS Code.
- Use `print()`, comments, variables, and basic data types.
- Work with strings, numbers, and user input.
- Use arithmetic and comparison operators.
- Make decisions with `if`, `elif`, and `else`.
- Repeat tasks with `for` and `while` loops.
- Work with lists and dictionaries.
- Write functions and understand parameters and return values.
- Read error messages and practise debugging.

### Suggested mini-projects
- Greeting and personal information program.
- Simple calculator.
- Number-guessing game.
- Expense tracker using lists and dictionaries.
- Text-based quiz.

**Milestone:** Write a small Python program from a blank file and explain how it works.

## Phase 2 — Days 31–60: Build useful programs

### Topics
- Read and write text files.
- Handle errors with `try` and `except`.
- Import standard-library modules.
- Organize code into reusable functions and modules.
- Understand basic classes and objects.
- Use Git commits to track changes.
- Read project documentation and practise breaking down requirements.

### Suggested mini-projects
- Command-line notes manager.
- File organizer in a test folder.
- Quiz with score tracking.
- Simple sales or expense report from sample data.

**Milestone:** Finish one small project with a clear README and example usage.

## Phase 3 — Days 61–90: Portfolio and next steps

### Topics
- Refactor an earlier project for readability.
- Write useful README files and document decisions.
- Practise Git branches and reviewing changes.
- Learn basic Linux terminal navigation and file operations.
- Explore HTTP, JSON, and APIs at an introductory level.
- Review HTML, CSS, and JavaScript fundamentals if web development remains a goal.
- Explore Solidity only after comfortable programming and basic development-tool skills.

### Suggested project
Build one polished, beginner-sized project that solves a real problem, includes instructions, and demonstrates what you learned.

**Milestone:** Publish a portfolio-ready project and write a short reflection on strengths and next learning goals.

## Weekly review checklist

- [ ] I ran code I wrote myself.
- [ ] I completed at least one exercise.
- [ ] I investigated an error instead of ignoring it.
- [ ] I documented a useful lesson.
- [ ] I committed meaningful progress to GitHub.
- [ ] I identified the next small step.

## Flexible pace

If a topic is difficult, spend additional days practising it. The aim is durable understanding and a growing portfolio, not racing through a calendar.
