## First concepts to practise

1. Run a Python file from VS Code.
2. Use `print()` to display text and values.
3. Store values in variables.
4. Ask the user for input with `input()`.
5. Convert input to a number when needed.
6. Use conditions to make a decision.
7. Repeat a task with a loop.
8. Put reusable logic into a function.
