## Learning roadmap

1. **Python foundations** — variables, data types, input/output, conditions, loops, lists, dictionaries, and functions.
2. **Practical Python** — file handling, modules, error handling, and organizing code.
3. **Automation projects** — build small tools that solve real problems and practise testing them.
4. **Developer workflow** — use GitHub to document changes, write clear commit messages, and explain projects.
5. **Next foundations** — explore Linux command-line skills and web/API basics; approach Solidity after building a comfortable programming foundation.

See the [90-day roadmap](docs/90-day-roadmap.md) for a flexible phase-by-phase plan, the [Python learning log](docs/python-learning-log.md) to record sessions, and the [Python foundations workbook](python/python-foundations.md) for hands-on practice.

## Recommended learning workflow

For each topic:
1. Read a short explanation.
2. Type and run an example yourself.
3. Change the code and predict the result.
4. Complete a small exercise without copying the solution first.
5. Record what you learned and any error you solved.
6. Commit meaningful progress to GitHub.

## Learning setup

- Visual Studio Code with Python support/Pylance.
- A Python practice folder and small Python files such as `hello.py`.
- Use the Python version that your environment supports; for new projects, prefer a currently supported release when practical.

## Goal

Build confidence with Python, develop useful automation tools, and publish a small portfolio of understandable projects over 90 days.

**Principle:** Consistency over intensity. Understand the code you write, ask questions, and build one small step at a time.
